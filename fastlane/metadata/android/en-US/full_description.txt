<p><i>DistroHopper</i> is a home screen replacement for Android that can resemble a number of different Linux desktops, including Ubuntu’s Unity desktop, elementary OS’s Pantheon desktop and the Gnome desktop.</p>
<p>Features include a couple of different themes, a search feature which allows you to search from a multitude of different search sources (both local and remote), and customisation options.</p>
<p><b>Use of the Accessibility API:</b> DistroHopper optionally uses Android’s AccessibilityService API for a single, narrowly scoped purpose: to open the notification shade when you perform a swipe gesture on the home screen. This is the only supported way for a non-system launcher to open the notification shade, because the equivalent system API (StatusBarManager) is not available to regular apps. The service performs only this one action (GLOBAL_ACTION_NOTIFICATIONS). It does not read, collect, observe, or transmit any screen content, and it observes no accessibility events. The service is entirely optional and disabled by default — it takes effect only after you explicitly enable it in your device’s Accessibility settings and map it to a gesture, and you can disable it at any time from those same settings.</p>
